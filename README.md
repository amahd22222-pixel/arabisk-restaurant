# ARABISK Restaurant & Cafe

A bilingual Arabic/English restaurant website with an admin dashboard, built around the visual identity of the supplied ARABISK menu.

## Planned apps
- `apps/web` — customer-facing menu and restaurant website
- `apps/admin` — admin dashboard
- `apps/api` — backend/API
- `packages/ui` — shared visual system
- `packages/menu-data` — menu seed/content model

## Brand direction
The UI follows the supplied menu's visual language: deep black, warm gold, ivory/cream surfaces, elegant typography, generous spacing, premium restaurant photography, and RTL-first Arabic support.

## Security
Secrets and environment files are excluded from Git. Never commit API keys, database credentials, or production secrets.
